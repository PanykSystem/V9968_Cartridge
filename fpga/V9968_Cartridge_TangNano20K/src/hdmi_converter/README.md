# hdmi_converter

V9968 の映像出力 (clk42m 42.95454MHz, 1368clk/line, 有効 720x480) を、
ラインバッファ (FIFO) を介して HDMI 720x480 (clk28m 28.63636MHz) に変換する。

## クロック

| クロック | 生成 | 周波数 |
|---|---|---|
| clk14m | 源振 | 14.31818MHz |
| clk42m | u_pll2 CLKOUTD (clk14m x 3) | 42.95454MHz |
| clk143m | u_pll (clk14m x 10) | 143.18180MHz (TMDS シリアライザ) |
| clk28m | Gowin_CLKDIV (clk143m / 5 = clk14m x 2) | 28.63636MHz (ピクセルクロック) |

clk28m : clk42m = 2 : 3 が厳密に成り立つため、入力 1 ライン (1368 clk42m) と
出力 1 ライン (912 clk28m) の周期は完全に一致する。
2 つの PLL 間の位相は不定なので、クロック乗せ換えは非同期 (Gray コード + 2FF 同期) で行う。

## 出力タイミング

| 項目 | 値 |
|---|---|
| H total | 912 |
| H sync | 0..61 (62clk) |
| H active | 122..841 (720clk) |
| V sync | 0..5 (6 lines) |
| V active | 36..515 (480 lines) |
| V total | 入力フレームの実測ライン数 (60Hz: 524, 50Hz: 626)。入力なし時は 524 |

水平周期と垂直ライン数が入力と完全に一致するため、ロック後は入出力の位相差が一定のまま保たれる。
垂直ブランキングの伸縮による同期調整は行わない (映像の揺れが発生しない)。
出力の HS/VS/DE はアクティブ High (hdmi_tx の SYNC_POLARITY "NEGATIVE" で反転して送出)。
フレームレートは V9968 と同一 (約 59.94Hz / 50.1Hz)。

## 構成

- ラインバッファ: 2 ライン x 1024 ワード x 24bit のデュアルクロック RAM (BSRAM 3 個)
  (書き込み clk42m, 読み出し clk28m, 読み出しレイテンシ 1clk)。
- 書き込み中のラインを追いかけて読み出す。書き込み (1 画素/clk42m, 720 画素で 0.53 ライン) は
  読み出し (1 画素/clk28m, 0.79 ライン) より速いので、書き込み開始後に読み出しを始めれば追い越さない。
- ポインタ (4bit Gray, 2FF 同期) は、書き込み側が「書き始めたライン数」、読み出し側が「読み終えたライン数」。
- ロック時に出力の水平位相を一度だけ合わせ、読み出し開始を書き込み開始の 0.5 ライン (456clk) 後に固定する。
  余裕は、追い越し側 0.5 ライン、2 ライン先の上書き側 0.7 ライン。
- clk42m 側でフリーランの 1368 カウンタにより VS 立ち下がり間隔をライン数として計測し、
  トグル同期で clk28m 側へ渡す。
- 書き込みは、直前フレームの長さが妥当 (517..1022 ライン) な VS 立ち下がりから開始する。

## 状態遷移 (clk28m)

| 状態 | 動作 |
|---|---|
| REQ / REL | 再同期。clk42m 側へ要求を送り、FIFO 両側をクリアするハンドシェイク |
| ACQ | v = 35 (有効表示直前) で待機。フレームの 1 ライン目の書き込み開始を検出したら h_count = 578 として LOCK へ (この時だけ HS 周期が乱れる) |
| LOCK | 計測したフレーム長で垂直カウンタを周回させて表示 |
| FREE | ACQ が 2000 ライン経過しても開始できない (入力なし) 場合、524 ラインの黒画面を出力 |

LOCK 中に以下を検出すると再同期 (REQ) する。

- 入力フレーム長が変化した、または無効になった (50/60Hz 切り替えなど。エラー扱いしない)
- 毎フレームの有効表示直前で、書き込み開始済みのラインが 1 ラインでない
- underflow: 有効ライン開始時に、そのラインの書き込みが始まっていない
- overflow: ライン書き込み開始時に、2 ライン前のラインがまだ読み終わっていない
- input_error: 1 ラインの画素数が 720 でない、1 フレームのライン数が 480 でない、VS 時に DE が有効

## ポート

| ポート | 方向 | 説明 |
|---|---|---|
| reset_n | in | 非同期リセット (各クロックドメインで同期解除) |
| clk42m, clk28m | in | 入力 / 出力クロック |
| video_de, video_vs, video_r/g/b | in | vdp_video_out の出力 (video_vs はアクティブ Low) |
| display_hs/vs/en, display_r/g/b | out | hdmi_tx へ。RGB はブランキング中 0 |
| locked | out | LOCK 状態 |
| overflow, underflow, input_error | out | スティッキーな診断フラグ (reset_n でのみクリア)。変換自体は自動復帰する |

## シミュレーション

`test001\run.bat` (ModelSim)。clk85m / clk42m / clk28m を厳密な整数比で生成し、
位相 (+PHASE [ps], +DIVPHASE) を振って以下を確認する。

| SCENARIO | 内容 |
|---|---|
| 0 | 60Hz 定常 + 表示中のハードリセット。全画素一致、フレーム欠落なし、周期 524x912 固定、読み出し開始が書き込み開始の約 0.5 ライン後 |
| 1 | 50Hz 定常。周期 626x912 固定 |
| 2 / 3 | 1 ラインだけ 719 / 721 画素 → input_error 後に再ロック |
| 4 | 最終ライン欠落 → underflow 後に再ロック |
| 5 | 読み出しポインタ固定 → overflow 後に再ロック |
| 6 | 途中から DE 停止 → underflow 後に再ロック |
| 7 | 60→50→60Hz を任意ラインで切り替え → エラーなしで再ロック |
| 8 | 入力なし → FREE で 524x912 周期の VS を出力 |

`+DEBUG` を付けると状態遷移を表示する。

## 注意

- 50Hz 時の 626 ライン出力は CEA 規格外のため、モニタが受け付けるかは実機確認が必要。
